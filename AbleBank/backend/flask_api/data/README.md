# Data Directory

This directory stores all persistent data for the AbleBank Copilot application.

## Contents

- **JSON Data Files**: Transaction data stored in date-formatted JSON files
  - Example: `data_20250503_140223.json`
- **Embeddings File**: `embeddings.json` contains vector embeddings of transaction data for semantic search
- **Data Log**: `data_log.txt` tracks data processing operations and timestamps

## Data Format

### Transaction Data Files

Each JSON file contains an array of transaction objects with the following structure:
```json
{
  "transaction_id": "string",
  "merchant": "string",
  "amount": "number",
  "category": "string",
  "date": "ISO timestamp",
  "type": "credit|debit"
}
```

### Embeddings File

The `embeddings.json` file maintains a mapping between transaction data and their vector embeddings:
```json
{
  "transaction_id": {
    "embedding": [float_array],
    "content": "string description of transaction"
  }
}
```

## Data Flow

1. Transaction data is generated by the `bot/generator.py` module
2. Data is processed by `bot/pathway_processor.py`
3. Raw data is stored in JSON files in this directory
4. Embeddings are created and stored in `embeddings.json`
5. Data is retrieved by API endpoints when requested

## Persistence

In a production environment, this file-based storage would be replaced with a proper database. For demonstration purposes, this directory serves as a simple persistence layer that simulates banking data storage.
